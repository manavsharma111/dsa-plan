# ⚡ DSA Tracker Chrome Extension (Auto-Capture)

Auto-captures your code, runtime, and memory whenever you get **Accepted** on **LeetCode** or **GeeksForGeeks**, and automatically syncs it with your **DSA Tracker Cloud**!

---

### 🚀 How to Install in 30 Seconds:

1. **Open Chrome / Brave / Edge** and type this in your address bar:
   ```text
   chrome://extensions
   ```
2. Toggle **"Developer mode"** to **ON** in the top-right corner.
3. Click the **"Load unpacked"** button in the top-left corner.
4. Select this directory:
   ```text
   C:\CORE SUBJECT\best\dsa\extension
   ```
5. Done! The extension is installed and ready.

---

### ⚙️ Quick Setup:

1. Click the **DSA Tracker (⚡)** icon in your browser toolbar.
2. Enter your **Sync Key** (as displayed on your DSA Tracker dashboard).
3. Select your **Backend API**:
   - **Live Cloud (Render)** ➔ Default `https://dsa-plan-backend.onrender.com`
   - **Localhost** ➔ When running the backend locally on port 5000.
4. Click **"Save Settings"**.

---

### 🎯 How it Works:
- Whenever you submit a solution on LeetCode or GeeksForGeeks and get **"Accepted"**:
  - The extension displays a floating confirmation banner in the bottom-right corner:
    `🚀 DSA Tracker Cloud Sync: [Problem Name] Synced!`
  - Solution code, runtime, memory, and submission timestamp are immediately saved to your cloud database.
  - Refreshing or opening your DSA Tracker dashboard will instantly show the problem marked as **Solved & Scheduled for Revision**!
