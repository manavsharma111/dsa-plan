Key Concepts — Know the Difference

The four core collection patterns tested in almost every coding interview.

Term Meaning Typical Technique
Subarray Contiguous part of an array (order preserved).
Sliding Window Prefix Sum Kadane's
Substring Contiguous part of a string.
Sliding Window Two Pointers
Subsequence Delete some elements; order kept, not necessarily contiguous.
DP (LCS) DP (LIS) Recursion
Subset Any selection of elements (order does not matter).
Backtracking Bitmask
💡
Rule of Thumb:
• Contiguous (Subarray / Substring) → Sliding Window or Prefix Sum • Ordered, Non-Contiguous (Subsequence) → Dynamic Programming (DP) • Unordered Selection (Subset) → Backtracking / Bitmask
